# Odin Admin Dashboard

This is my second project from the **Intermediate HTML and CSS** at [The Odin Project](https://theodinproject.com). The goal is to build a basic Admin Dashboard design to practice intermediate HTML and CSS Grid layout skills.

## 🎯 Objectives

- Implement complex web layouts using CSS Flexbox and Grid.
- Use icons and images with appropriate dimensions and object fitting.
- Master the use of CSS Flexbox and Grid.

## 🛠️ Tech Stack

- **HTML5**
- **CSS3 (Flexbox & Grid)**
- **Git & GitHub**
